# ⚡ Smart Prefetch

> Précharge automatiquement les pages web en arrière-plan pour qu'elles s'ouvrent quasi instantanément.

**Auteur :** Timéo Bonnin · **Version :** 2.0.0 · **Licence :** Open Source

---

## 🚀 Installation

1. Télécharger le dossier `smart-prefetch/`
2. Ouvrir [`chrome://extensions`](chrome://extensions)
3. Activer le **Mode développeur**
4. Cliquer **Charger l'extension non empaquetée**
5. Sélectionner le dossier

---

## ✨ Fonctionnalités

- 🚀 Prefetch automatique de tous les liens
- 🖱️ Survol prédictif
- 👁️ Viewport intelligent
- 📜 Scroll rapide
- 🧠 Chaîne de Markov
- 🎨 Bulle Fluent en haut à droite
- 📛 Badge live sur l'icône
- ⚙️ Page d'options complète
- ⌨️ `Ctrl+Shift+P` / `Ctrl+Shift+A`
- 🚫 Blocklist par défaut
