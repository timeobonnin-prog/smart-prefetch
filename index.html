Smart Prefetch

Précharge automatiquement les pages web en arrière-plan pour qu'elles s'ouvrent quasi instantanément.

Chrome 102+ Edge · Brave Manifest V3 Open Source


🚀 Installation

# 1. Télécharger le dossier smart-prefetch/ # 2. Ouvrir chrome://extensions # 3. Activer le Mode développeur # 4. Cliquer Charger l'extension non empaquetée # 5. Sélectionner le dossier

✨ Fonctionnalités

  • Prefetch automatique de tous les liens
  • Survol prédictif et viewport intelligent
  • Scroll rapide et chaîne de Markov
  • Bulle Fluent en haut à droite
  • Badge live sur l'icône
  • Page d'options complète
  • Raccourcis Ctrl+Shift+P / Ctrl+Shift+A
  • Blocklist par défaut (YouTube, X, banques…)
