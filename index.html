Installation

Prêt en 30 secondes.

Pas de store, pas de compte, pas de configuration. Chargement direct en mode développeur.

installation.sh
# 1. Placer le dossier smart-prefetch/ où tu veux
cd ~/Downloads/smart-prefetch
 
# 2. Ouvrir Chrome
open chrome://extensions
 
# 3. Activer le Mode développeur (en haut à droite)
# 4. Cliquer "Charger l'extension non empaquetée"
# 5. Sélectionner le dossier smart-prefetch
✅ Prêt à naviguer plus vite.
