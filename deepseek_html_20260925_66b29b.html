Fonctionnalités

Scroll rapide

Chaîne de Markov

L'extension apprend tes habitudes de navigation et prédit ta prochaine page.

🎨

Bulle Fluent

Badge live

Installation

Prêt en 30 secondes

Pas de store, pas de compte, pas de configuration. Chargement direct en mode développeur.

# 1. Télécharger le dossier → Placer smart-prefetch/ où tu veux sur ton PC # 2. Charger dans Chrome 1. Ouvre chrome://extensions 2. Active le Mode développeur (en haut à droite) 3. Clique Charger l'extension non empaquetée 4. Sélectionne le dossier smart-prefetch # 3. Vérifier → Va sur Wikipédia, ouvre F12 → Network → Tape prefetch dans le filtre : les requêtes défilent ✅
